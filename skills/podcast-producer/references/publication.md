# 播客文字稿导出 · 2026-10-22.1

产品止于导出当前剪后播客长文稿。用户自己的 Agent 负责后续选材、重组、事实核查和文风改写；不在导出时自动代替作者写公众号文章、小红书内容或模仿文风。

## 长文稿

直接读取当前工程中实际保留的正文，按剪后播放顺序整理为段落，导出 Markdown；既有 TXT 导出保留。保留原话、英文名、口癖、玩笑、例子、重复强调及观点限定，不调用模型删改文字、润色或补写。转写错误可以由用户编辑，不能在导出时凭参考稿或模型猜测替换。

片头是从正文复制的精句时，正文导出不重复收录片头副本；正文中本来保留的重复表达不能因此合并。用户已删除的字、已剪除的音频范围不能从录前稿恢复。只导出精句的工程仍保留现有内容。

无须绑定 AI API，不受 API 余额、联网或改写任务影响；不能把历史 AI 改写结果当作当前导出。只做排版的文字稿不声称已经书面化或经过外部事实核查。

## 简介与时间戳

保留独立、按需生成的发布资料功能。可以调用用户绑定的模型提取标题、简介和真实章节，但不能连带改写长文稿，或借此加载个人文风档案。章节必须定位到实际剪后段落，时间由真实配乐和倍速排程计算，不能由模型猜测。

用户继续剪辑后重新导出，避免使用旧版本文字和时间戳。后续如明确要求另行改写文章，作为用户自己 Agent 的独立写作任务处理，不把一次文章的风格或观点写成所有用户的默认规则。
