# 使用自己的 Agent

在同一台 Mac 上运行另一个本地 AI 即可，不需要另一台电脑。AI 需要获得本仓库、指定素材文件和终端的访问权限；若要操作网页，还需具备这台电脑上的浏览器控制能力。纯云端对话通常无法直接读取本机文件或访问本机的 `127.0.0.1`。

## 给本地 AI 的任务指令

将仓库目录交给 AI，再提供自己的录音、可选参考稿和配乐路径。下面的指令不包含密钥：

> 请先阅读本仓库的 AGENTS.md、skills/podcast-producer/SKILL.md 及其引用的编辑规则和运行方式。检查并启动本机 PodCut，使用我指定的素材完成播客初剪，再打开结果工程让我精剪。先确认录音顺序、停顿阈值、是否清理吸气、是否要精句以及配乐选择；不确定时向我询问。保留大部分有效表达，清理失败起句、改口和同义重录，保护完整观点、英文专名及稿外的有效内容。通过现有工具获取字界，不凭文字编造时间戳。保存独立、可复原的工程，核验保存和播放后再交付网页地址。需要新 API 服务或付费调用时先说明数据去向并取得授权；不要将密钥写入代码、工程或公开文件。

## 环境和服务

先按 [安装指南](getting-started.md) 准备 Node.js 22+、FFmpeg / ffprobe，在仓库根目录执行：

```sh
npm ci
npm run doctor
npm start
```

默认网页为 `http://127.0.0.1:5188/`。源码、配置和 `.podcast-drafts/` 均属于当前安装目录。已有其他 PodCut 安装时，使用本副本独立的端口与工程，不结束其他安装的进程。

新录音转写需要配置火山语音凭据；网页 Agent 初剪需绑定兼容 Chat Completions 的 API，或使用 `.env.local` 中的 DeepSeek 配置。录音转写会向语音服务发送音频，内容分析会向所选模型发送文字；费用由对应账户承担。本地 AI 的聊天订阅不会自动成为 PodCut 的 API 凭据。密钥只保存在本机，不发到 GitHub。

命令行的 `prepare` 还需要运行中的本机字界校准服务；首次使用按安装指南执行 `npm run setup:alignment`。下载模型可能耗时，不能把缺少模型时的基础启动当作完整初剪链路已验证。

## 两种执行入口

网页入口支持导入录音、绑定 API、上传参考稿、配置片头和配乐，再运行「Agent 初剪」。片头可选不添加、用户选择或授权自动选择。结果保存后在同一网页试听和精剪。

命令行入口见 [完整运行方式](../skills/podcast-producer/references/workflow.md)：

```sh
node agent-tools/episode.mjs prepare /绝对路径/episode.json /绝对路径/本期工作目录
```

目前 CLI 的 `prepare` 会生成片头候选并等待选择；`assemble` 要求用户确认至少两个不同精句 ID。例如用户已选择 `q1`、`q3` 后：

```sh
node agent-tools/episode.mjs assemble /绝对路径/本期工作目录 episode-demo q1,q3 --confirmed
```

不需要片头时使用网页入口；不要捏造选择或绕过 CLI 校验。CLI 当前使用配置的 DeepSeek 接口进行内容分析，不能仅因运行它的本地 AI 已有模型订阅，就宣称不需要额外 API。

生成结果后，打开命令输出的 `http://127.0.0.1:5188/?project=<project-id>`。CLI 输出地址不会自动证明浏览器已打开或播放正常；执行任务的 AI 需要实际打开并核验。`.podcast` 是包含 `current.json`、素材和快照的整个工程文件夹，不能只传一个 JSON。

## 交付检查

- 使用独立项目编号，保留源录音和原稿；避免覆盖正在精修的工程。
- 核对删除接缝、保留字、英文和配乐插入点，试听之后再称为完成。
- 吸气检测仍可能漏检或误判，结果可在网页复原和精修。
- 修改保存后回到主页重新打开，确认工程仍在。
- 导出的长文稿使用当前剪后原话；文章改写交给使用者自己的 Agent。

发布前的合成回归测试用于检查编辑、保存与排程，不代表所有真实录音的识别和吸气检测准确率，也不代表大型模型已在每台新机器上安装验证。
