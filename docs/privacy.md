# 隐私与本机数据

本机副本的磁盘数据保存在启动目录内的 `.podcast-drafts/`，包括历史工程、音频资产、快照、导出任务，以及部分服务配置。浏览器也保存草稿和素材缓存。它们不是云端账号数据，不会因源码开源而自动分享。

网页绑定的 AI Key 当前保存于 `.podcast-drafts/agent-ai.json`，文件以受限权限写入，**不是加密密钥库**。环境变量保存在用户自行创建的 `.env.local`。不要把这两个位置、整个项目工作目录或浏览器配置打包发给他人。

转写会向所配置的语音识别服务发送录音；Agent 分析会向所选 AI 发送所需的转写文本、参考稿和配置。连接测试也会调用服务。当前本机校准和音频导出在本机运行。服务商的数据保留与收费规则需由使用者单独确认。

备份自己的项目时，应在保存完成后备份本副本的 `.podcast-drafts/`，同时注意其中可能包含 Key。浏览器独有的素材缓存不保证包含在磁盘备份中，请保留原始录音和配乐。源码 ZIP 不是剪辑工程备份。

当前服务面向本机单用户，尚未完成公网多用户身份认证、账户数据隔离、配额和计费等改造。端口保持绑定在回环地址；不能仅改为公开监听就当成安全的收费平台。

报错反馈只提供复现步骤、软件版本和脱敏错误信息；不要公开上传真实录音、参考稿、密钥或整个草稿目录。
