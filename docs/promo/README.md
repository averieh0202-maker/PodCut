## 画面依据

- **长句删除**：真实删除 15 字，音频减少 2.78 秒，画面按一位小数显示 2.8 秒。
- **字界、音乐参数、导出入口**：实际网页操作截图，经裁切、缩放和后期动画处理。
- **Agent 效果样例**：预置说话人和逐字时间的合成测试工程。Codex 提供两处重复／失败起句的删除决定，经项目计划校验与真实剪辑引擎执行；停顿分析处理 4 处含吸气形态噪声的间隔，总共移除约 6.27 秒。对比画面由这些结果排版生成。没有在此次演示中调用语音识别或付费模型 API，不作为真实语音检测准确率证据。
- **配乐拖入和类型选择**：后期动作示意，真实连续拖入流程尚待补录；音乐素材、参数编辑控件来自实际网页截图。
- **导出**：展示导出入口，没有以演示镜头替代完整导出验证。

所有素材均不包含个人录音、API 密钥或私人历史工程。尚未对外发布。
