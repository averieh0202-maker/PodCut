# V06 · 连续动效版

[播放与分段跳转](index.html) · [全部版本](../index.html)

36 秒 / 1920 × 1080 / 60 fps / 有声。固定深色舞台，同一苹方简体字系覆盖中英文和数字，仅使用正常字重层级。没有浅色整屏或黑白切换。

## 本版动作

- 选区扫过长句；被删音频段抬起移出，剩余音频收拢。
- 拖动字界，结束数值连续变化；镜头跟随重点推近。
- 改口和重复句划掉、移出，保留正文补位；吸气停顿一并淡出。
- 素材拖入轨道；背景／过场模式切换时，人声位置连续移动；裁短配乐后人声随之收拢。
- 导出菜单的选择变成各类文件动效。

这是根据实录内容重绘的解释性广告动画，不是产品新 UI 或连续录屏。整体波形、配乐轨道关系、文件生成动作为后期示意；字界局部波形轮廓来自实录截图。Agent 采用合成样例与预置说话人，经真实引擎处理，未运行实时 API。

配乐和音效为项目原创合成，没有采样外部歌曲。系统字体未打包分发。旧版本保持原样。
