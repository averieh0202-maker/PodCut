画面来源与演示边界
  • 真实网页截图经剪辑、裁切、镜头和光影处理。Agent 对比使用预置说话人和字界的合成样例，由 Codex 提供删除判断，再由真实剪辑引擎执行；未实跑语音识别或付费模型 API。
  • 配乐拖拽与模式选择为后期动作示意，参数编辑来自真实网页画面。导出画面展示菜单入口。
  • 音乐与音效为程序原创合成，没有采样外部歌曲。没有采用苹果的画面、标志或配乐，也不表示与苹果存在关联。
  • 影片默认静止，点击后播放；可以直接看封面或阅读说明。每次交付独立编号保存，不覆盖此前成片。
