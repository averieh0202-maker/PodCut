# 开源准备与发布范围

本源码仓库与原使用环境分离，发行范围是本机单用户源码版。发布源码不等于部署可供多人使用的在线服务。

## 已完成

- 自有代码采用 AGPL-3.0-only，保留完整 LICENSE。
- 代码、服务、端口和草稿存储独立；不包含原使用环境 Git 历史。
- 排除真实录音、参考稿、个人文风、密钥、历史工程、模型、导出和私人声学测试样本。
- 收集 npm 依赖许可文本及版本清单，保留字体声明，整理可选 Python 依赖元数据。
- 不分发授权尚未确认的 Edge 合成演示朗读，保留本机既有文件及加载能力。
- 补充安装教程、隐私说明、贡献说明和不调用 API 的环境检查。

## 本次源码包不含

`node_modules/`、`dist/`、`.env.local`、`.podcast-drafts/`、模型权重、虚拟环境、真实媒体、私人诊断页、在线 TTS 输出及 Git 历史。

使用 `python3 tools/package-source.py` 生成 `releases/PodCut-source.zip`；工具先执行发布扫描，再按 Git 候选文件清单打包。不要使用 Finder 的整个目录压缩替代，否则可能带入本机数据。打包脚本需要在 Git 工作目录运行。

## 后续交付边界

1. 下载与反馈入口以 README 的仓库地址为准；贡献代码时保留项目署名及许可证。
2. 发布在线服务或预编译浏览器产物前，提供本项目对应版本及 MPL 依赖源码获取入口；不能以源码副本测试代替多人服务部署验证。
3. 容器、模型镜像或二进制安装器需要单独核对实际打包内容。时间戳模型许可尚未确认，所以本次不分发任何模型。
4. macOS 的构建测试不代表 Windows / Linux 音频后端和模型安装均通过；大型模型的新机器安装仍未验证。
5. 自动扫描只覆盖已实现的规则，不能证明不存在所有未知敏感信息。每次发布仍需检查实际文件清单。
